# telegram-gift-bot

Telegram-бот: розыгрыш подарков, магазин за Stars, VIP, профили — и **режим «Секретарь»**
(ИИ Groq в личке через Telegram Business).

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN=...      # обязательно
export ADMIN_ID=...       # твой Telegram ID
python bot.py
```

Хранилище: PostgreSQL (`DATABASE_URL`), иначе JSON-файл `bot_state.json`.

## Режим «Секретарь»

Управление: `/admin` → **🤖 Секретарь** (доступно только владельцу, `ADMIN_ID`).

Что умеет:
- ИИ (Groq) отвечает собеседникам в личке от твоего аккаунта, **ответы жирным**;
- удалённые и изменённые сообщения собеседников приходят тебе в бота (с юзернеймом и ID);
- отчёт о каждом ответе ИИ + кнопка «🚫 В исключения ИИ»;
- **исключения** — без ограничения количества (`@username` или ID): в их чатах ИИ молчит;
- пауза ИИ после твоего собственного ответа (выкл / 5 / 10 / 15 / 30 мин / 1 / 3 / 12 ч);
- свой промпт, выбор модели, кнопка «🧪 Проверить ИИ».

### Подключение к аккаунту (Telegram Business)
1. @BotFather → `/mybots` → бот → Bot Settings → **Business Mode** → включить.
2. На аккаунте нужен Telegram Premium.
3. Настройки → Telegram для бизнеса → **Чат-боты** → укажи бота, выбери чаты, включи право «Отвечать на сообщения».
4. Бот пришлёт подтверждение. Чужие подключения он игнорирует.
5. Один раз нажми `/start` у бота — иначе он не сможет писать тебе отчёты.

### Ключ Groq
Не храни ключ в коде и в репозитории. Два способа:
- в админке: **🤖 Секретарь → 🔑 Ключ Groq** (хранится в БД, сообщение с ключом удаляется);
- переменная окружения `GROQ_API_KEY`.

### Ограничения
- Telegram не присылает содержимое удалённых сообщений — бот показывает то, что успел увидеть.
  После перезапуска бота сообщения, пришедшие раньше, показать нельзя.
- Исходящие сообщения ИИ идут через Business API, поэтому нужен включённый Business Mode у бота.

## Безопасность репозитория
- Делай репозиторий **приватным**, если оставляешь `DATABASE_URL` по умолчанию в `bot.py`.
- Файлы `database.py` и `gift_account.py` больше не нужны — всё уже внутри `bot.py`.
